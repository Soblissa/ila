# LUSD Testautomatisierung

Dokumente zur Machbarkeitsstudie Testautomatisierung im Projekt LUSD.

## Inhalt

- `Machbarkeitsstudie_Testautomatisierung_LUSD.docx` — Vollständige Machbarkeitsstudie (Autor: Tobias Gudd, HZD Hessen, 2026)

## Zusammenfassung

Die Studie untersucht, ob und wie die manuelle Testdurchführung für die Webapplikation LUSD automatisiert werden kann.

**Ergebnis:** Testautomatisierung ist grundsätzlich machbar. Mehrere Rahmenbedingungen müssen noch geklärt werden (Infrastruktur, Testdaten, Verantwortlichkeiten).
